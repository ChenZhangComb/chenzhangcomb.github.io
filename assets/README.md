# 网站附件目录

请通过 `editor.html` 的「文件库」上传文件。可先建立文件夹，进入后继续建立子文件夹；完整网站包会将原文件保存到本目录下的 `uploads/`，并保留层级结构。

- 编辑器不设单文件大小或文件库总量上限；实际可用容量取决于浏览器存储配额、设备空间和内存，发布时仍受 GitHub 等托管平台限制。页面中的 MB 按 1,048,576 字节计算。
- 头像和简历上传后，复制文件库显示的网站路径，填入基本信息的对应地址字段。
- 论文条目支持直接上传 PDF、数据和附件，也可选择文件库中已有的文件。较大的数据集可填写已有的完整外部下载链接。
- 编辑器上传先保存到当前浏览器，不会改写此目录或自动发布。完成后下载完整网站 ZIP，解压并将全部目录一起更新到 GitHub。
- JSON 文字备份只记录文件引用，不包含附件。包含附件的备份请使用完整网站包。
- 导出包中的 `file-data/` 位于网站根目录，是重新打开编辑器时恢复附件所需的数据，请勿删除。也请保留 `files.js`、`site-source.js` 和空文件夹中的 `.gitkeep`。

旧版手动放置在本目录中的 `avatar.jpg`、`cv.pdf`、论文等资产，请先上传到文件库，并把原链接更新为文件库提供的新路径。完整 ZIP 会阻止无法打包的本地引用；不要依赖导出包自动收集手动添加的文件。

发布后请保持文件名、大小写与目录结构不变，以免附件链接失效。详细发布步骤见网站根目录的 `README.md`。
